## Implementation Steps

### Step 1: AM demodulator core (`src/audio/demod.rs`)

- [ ] 1.1: Frequency shift (mix to baseband)
  - Complex multiplication with local oscillator: `sample * e^(-j2πft)`
  - Needs: cursor frequency, center frequency, sample rate
- [ ] 1.2: Low-pass FIR filter design
  - Windowed sinc method (Blackman window)
  - Cutoff = channel_bw / 2
  - Filter taps depend on transition bandwidth
- [ ] 1.3: Decimation
  - Reduce sample rate: 2,048,000 / 48,000 ≈ factor 42
  - Only safe after LP filtering (prevents aliasing)
- [ ] 1.4: AM envelope detection (magnitude)
  - `audio = sqrt(I² + Q²)` — that's it for AM
- [ ] 1.5: DC removal filter
  - Simple IIR high-pass: `y[n] = x[n] - x[n-1] + α * y[n-1]` (α ≈ 0.995)
- [ ] 1.6: Unit tests for each stage
  - Frequency shift: verify tone moves to DC
  - LPF: verify out-of-band rejection
  - Decimation: verify output length
  - Envelope: verify correct amplitude extraction
  - DC removal: verify DC offset removed
- [ ] 1.7: Synthetic AM test signal generator
  - `carrier * (1 + m * sin(2π * f_audio * t))` at known frequency
  - Parameters: carrier freq, audio freq, modulation index
- [ ] 1.8: End-to-end demod test
  - Synthetic AM → full pipeline → verify audio tone at correct frequency and amplitude

## Technical Notes

### Frequency Shifting
Move the signal of interest to baseband (0 Hz) by complex multiplication:
```
shifted[n] = sample[n] * e^(-j * 2π * f_offset * n / sample_rate)

where f_offset = cursor_freq - center_freq
```
This is equivalent to tuning a radio — you center the desired signal at DC.

### FIR Low-Pass Filter
Windowed sinc method:
```
h[n] = sinc(2 * fc * (n - M/2)) * window[n]

where:
  fc = cutoff frequency / sample_rate (normalized)
  M = filter order (number of taps - 1)
  window = Blackman window for good stopband rejection
```
More taps = sharper filter but more CPU. For 25 kHz channel in 2.048 MHz: ~64-128 taps is sufficient.

### Decimation
After filtering, we can safely reduce the sample rate:
```
decimation_factor = floor(input_sample_rate / output_sample_rate)
                  = floor(2,048,000 / 48,000) = 42

output[n] = filtered[n * 42]
```
MUST filter first — decimating without filtering causes aliasing (high frequencies fold back in).

### AM Envelope Detection
For AM, the audio IS the amplitude of the signal:
```
audio[n] = |z[n]| = sqrt(I[n]² + Q[n]²)
```
This works because AM modulates information onto the carrier's amplitude.

### DC Removal
AM demod produces a DC offset (the carrier amplitude). Remove with a simple IIR high-pass:
```
y[n] = x[n] - x[n-1] + α * y[n-1]

α = 0.995 (for ~3 Hz cutoff at 48 kHz sample rate)
```

### Sample Rate Math
```
Input:  2,048,000 Hz (RTL-SDR)
Channel: 25,000 Hz (aviation AM standard spacing)
Decimation: 2,048,000 / 48,000 ≈ 42.67 → use 42
Output: 2,048,000 / 42 = 48,762 Hz ≈ 48 kHz

cpal output: 48,000 Hz (standard PCM audio)
Small rate mismatch handled by resampling or adjusting decimation.
```
